## About
A real estate card UI project for displaying property listings.

## Features
- Property images
- Property prices and titles
- Property type labels
- Location information
- Property details such as area, bedrooms, and bathrooms

## Technologies Used
- HTML5
- CSS3
- bootstrap

## How to Run
1. Clone or download this repository.
2. Open the project folder.
3. Open card.html in your browser.
